* Medical Departments

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/your-username/hospital-management.git
```

---

## Navigate

```bash
cd hospital-management
```

---

## Install

```bash
npm install
```

---

## Start Development

```bash
npm run dev
```

---

## Build

```bash
npm run build
```

---

## Preview

```bash
npm run preview
```
